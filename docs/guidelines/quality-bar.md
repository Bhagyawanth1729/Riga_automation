# Quality bar (V1.3 extract)

Full PDF: `docs/guidelines/Riga-Project-Guidelines-V1.3.pdf`.

## Prompt must

Original; allowed STEM domain; stumps ≥1 frontier model most of the time (official: ≤88% success on ≥1 of two models); reasoning not recall; well-formed LaTeX; unique answer (DNE illegal); explicit answer format; verifiable; self-contained; no shortcuts; not guessable; not a word puzzle; not a proof; not a single-paper result.

## Answer must

Be correct. Use only notation introduced in the prompt. Include units if the prompt did not.

## Solution must

Be correct step-by-step (final answer does not certify steps); support every claim; state answer-changing assumptions; be non-computational (calculator only); use consistent notation; start each step with `Step N`; end `Final Answer: $\boxed{...}$`; Answer box = same payload in `$...$`.
