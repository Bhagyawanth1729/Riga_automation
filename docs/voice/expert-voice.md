# How a PhD actually writes a closed problem

Read two or three problems from a real qualifier (your own field) before you draft. Then write *your* item, not theirs.

## Prompt skeleton that does not sound generated

1. Name the system in the first clause (cell, haplotype, Hamiltonian, enzyme).
2. Give the numbers with the units they were measured in.
3. State the one or two conventions a referee would ask about.
4. End with a single imperative: report / evaluate / give, plus the written form.

Bad: "In this problem, we will explore the Nernst equation in a comprehensive way and determine the cell potential."

Good: the Harned-cell prompt in `docs/examples/gold-harned-cell/task.md`.

## Solution skeleton

Each step is a move a colleague would write on a board:

1. What equation applies, and why this $n$, this $Q$, this ensemble.
2. Substitution and the arithmetic you actually did.
3. The object the prompt asked for, rounded the way the prompt said.

Do not narrate your cognition ("first I thought about…"). Do not congratulate the theory.

## Variation

If the last item you wrote opened with a cell diagram, the next one should not. Rotate: numerical table, pedigree, rate law, Hamiltonian, sequence plus a stated code table, circuit with element values.
