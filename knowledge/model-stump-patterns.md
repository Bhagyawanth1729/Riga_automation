# Legitimate ways frontier models miss (and illegal ones)

Use these as *design pressure*, not as templates. Each submitted problem still needs a new scientific object.

## Chemistry

- Activity / fugacity present in the data but dropped from $Q$
- Wrong $n$ on a cell reaction (Harned: $n=1$, not 2)
- Small-$x$ used when $x$ is not small; polyprotic dominant-species wrong
- Kinetic product vs thermodynamic product when both are chemically live
- Standard state $1\,\mathrm{m}$ vs $1\,\mathrm{M}$ vs $1\,\mathrm{bar}$ mixed silently

## Physics

- First-order perturbation vanishing, leading shift is second order
- Fermion vs boson spatial wavefunction when the Hamiltonian is spin-independent
- Which operator is actually measured after a specified basis rotation
- Relativistic vs Newtonian when $v$ is not obviously small but the prompt gives $c$
- Sign of induced emf / which face is high potential

## Biology

- Reading-frame consequence of a splice-site shift (phase stated)
- $D_t=D_0(1-c)^t$ forgotten; people report $p_Ap_B$ as the haplotype frequency
- Interference / coefficient of coincidence vs raw map sum
- Enzyme: $k_\mathrm{cat}/K_M$ vs $V_\max$ mixup when both numbers are given
- Which generation a pedigree probability is conditioned on

## Illegal (will be sent back)

- Word puzzles, ambiguous referents, hidden definitions
- Multiple choice, true/false, yes/no
- Proof prompts
- Contest chestnuts with the integers swapped
- Anything that is hard because the English is bad
