# Reviews

Use this folder when you are on `EK_Riga_Production / Riga Review`, not when you are the original author.

```bash
cp templates/review.md reviews/review-YYYYMMDD-001.md
```

You do not rewrite the problem or the answer. Light-edit solution-step grammar/LaTeX only. Solve independently. Decision: Accept / Needs Revision / Reject. Name error categories on send-back.

See `AGENTS.md` (Review mode) and `docs/platform/ui-fields.md` section B.
